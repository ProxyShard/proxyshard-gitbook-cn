# 代理位置不正确！

购买的代理有时可能会在 Dolphin (Anty)、AdsPower、Octo 或 IPQualityScore 和 Whoer.ru 等网站上显示错误的国家/地区。

主要问题是反检测浏览器和 Web 服务使用不同的数据库来确定 IP 地址位置，或者需要很长时间才能获取更新。其中一些，尤其是 Whoer.net，**不是中立来源**，因为他们自己出售代理，并可能出于营销目的故意扭曲数据。

我们完全依赖经过验证的 T**ier-1（最大）地理定位数据库**：

* **MaxMind** ([链接](https://www.maxmind.com/en/locate-my-ip-address))
* **DB-IP** ([链接](https://db-ip.com/api/))

这些站点是独立的，适合检查代理位置。

一旦这些数据库中的 IP 地址更新，我们就会立即将其出售。

**为什么反检测浏览器和某些服务显示错误的国家/地区？**

1. **数据更新延迟。** 一些反检测浏览器和网站每隔几周甚至几个月更新一次地理定位数据库。
2. **他们自己的算法。** 反检测浏览器可能使用过时的或替代的来源，这会导致差异。
3. **竞争偏见。** Whoer.net 和类似网站**不客观**，因为他们有兴趣推广自己的服务。

**我们的保证：**

* 所有代理均根据 **MaxMind、DB-IP 和 IP2Location** 数据**匹配指定位置**。
* 随着时间的推移（从几天到几周），所有数据库和网站都会同步，位置检测错误就会消失。

**❗ 在这种情况下，不提供退款或更换**，因为代理完全符合质量标准。我们总是在销售前检查地址，并保证其清洁度和主要地理定位数据库中的正确定位。
