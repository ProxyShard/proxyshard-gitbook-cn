# Bookmarks

<mark style="color:purple;">**Bookmarks**</mark> 让你只需设置一次书签，就能分发给所有配置文件或所选文件夹中的配置文件。点击 <mark style="color:purple;">**+ Add a bookmark**</mark>（或顶部的 <mark style="color:purple;">**+ New bookmark**</mark>）。<mark style="color:purple;">**Import from Chrome**</mark> 可导入你 Chrome 中的书签。

<figure>
  <picture>
    <source srcset="../../.gitbook/assets/shardbrowser-bookmarks-empty_black.png" media="(prefers-color-scheme: dark)">
    <img src="../../.gitbook/assets/shardbrowser-bookmarks-empty_white.png" alt="Bookmarks 页面">
  </picture>
  <figcaption>Bookmarks 页面</figcaption>
</figure>

在 <mark style="color:purple;">**New bookmark**</mark> 窗口中填写 <mark style="color:purple;">**URL**</mark>、标题（<mark style="color:purple;">**Title**</mark>）和文件夹（<mark style="color:purple;">**Folder**</mark>）。选择 <mark style="color:purple;">**Every profile**</mark> 会把书签添加到所有配置文件。点击 <mark style="color:purple;">**Save**</mark>。

<figure>
  <picture>
    <source srcset="../../.gitbook/assets/shardbrowser-bookmark-new_black.png" media="(prefers-color-scheme: dark)">
    <img src="../../.gitbook/assets/shardbrowser-bookmark-new_white.png" alt="填写字段并点击 Save">
  </picture>
  <figcaption>填写字段并点击 Save</figcaption>
</figure>

{% hint style="info" %}
下次启动配置文件时，书签会出现在所选文件夹中每个配置文件的书签栏里，位于名为 **ShardBrowser** 的书签文件夹内。你在配置文件中手动添加的书签保持不变。
{% endhint %}
