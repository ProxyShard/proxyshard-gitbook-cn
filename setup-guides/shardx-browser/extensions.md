# Extensions

<mark style="color:purple;">**Extensions**</mark> 用于存放可添加到配置文件的扩展。扩展只需添加一次，之后在需要的配置文件中启用即可。

点击 <mark style="color:purple;">**+ Add an extension**</mark>。可以通过 Chrome Web Store 链接、<mark style="color:purple;">`.crx`</mark> / <mark style="color:purple;">`.zip`</mark> 文件或文件夹添加扩展。

<figure>
  <picture>
    <source srcset="../../.gitbook/assets/shardbrowser-extensions-empty_black.png" media="(prefers-color-scheme: dark)">
    <img src="../../.gitbook/assets/shardbrowser-extensions-empty_white.png" alt="Extensions 页面">
  </picture>
  <figcaption>Extensions 页面</figcaption>
</figure>

在 <mark style="color:purple;">**Add from a link**</mark> 窗口中，粘贴扩展在 Web Store 的页面链接、扩展 id 或 `.crx` / `.zip` 的直链。对于 Web Store 链接，ShardBrowser 会自动提取 id 并下载扩展。点击 <mark style="color:purple;">**Download**</mark>。

<figure>
  <picture>
    <source srcset="../../.gitbook/assets/shardbrowser-extension-add-link_black.png" media="(prefers-color-scheme: dark)">
    <img src="../../.gitbook/assets/shardbrowser-extension-add-link_white.png" alt="粘贴链接并点击 Download">
  </picture>
  <figcaption>粘贴链接并点击 Download</figcaption>
</figure>

扩展会出现在列表中，并显示版本和大小。

<figure>
  <picture>
    <source srcset="../../.gitbook/assets/shardbrowser-extensions-list_black.png" media="(prefers-color-scheme: dark)">
    <img src="../../.gitbook/assets/shardbrowser-extensions-list_white.png" alt="扩展已添加">
  </picture>
  <figcaption>扩展已添加</figcaption>
</figure>

要在配置文件中启用扩展，请打开配置文件编辑（<mark style="color:purple;">**Edit**</mark>），进入 <mark style="color:purple;">**Extensions**</mark> 选项卡，勾选需要的扩展并点击 <mark style="color:purple;">**Save**</mark>。也可以在创建配置文件时，在 <mark style="color:purple;">**New profile**</mark> 窗口的 <mark style="color:purple;">**Extensions**</mark> 选项卡中直接选择扩展。

<figure>
  <picture>
    <source srcset="../../.gitbook/assets/shardbrowser-profile-edit-extensions_black.png" media="(prefers-color-scheme: dark)">
    <img src="../../.gitbook/assets/shardbrowser-profile-edit-extensions_white.png" alt="在配置文件中勾选扩展并点击 Save">
  </picture>
  <figcaption>在配置文件中勾选扩展并点击 Save</figcaption>
</figure>
