# Proxifier

{% hint style="danger" %}
此解决方案不支持 UDP 隧道！
{% endhint %}

{% hint style="info" %}
该计划是付费的；其试用期为31天。
{% endhint %}

## 安装 **Proxifier.**

点击[链接](https://www.proxifier.com/download/)下载Proxifier。然后安装并启动该程序。

<figure><img src="../../.gitbook/assets/image (29) (1).png" alt=""><figcaption></figcaption></figure>

## Proxifier设置

首先，指定代理服务器。打开 <mark style="color:purple;"> 代理服务器</mark> 选项卡。

<figure><img src="../../.gitbook/assets/image (28) (1).png" alt=""><figcaption></figcaption></figure>

## **添加代理**

使用“添加”按钮添加连接。

粘贴连接详细信息，指定所需的连接协议，然后单击“保存”。

<figure><img src="../../.gitbook/assets/image (94).png" alt=""><figcaption></figcaption></figure>

<figure><img src="../../.gitbook/assets/Image00003 (8).PNG" alt=""><figcaption></figcaption></figure>

请务必在保存之前进行检查。如果检查失败，则连接数据很可能不正确或指定的协议与订单中的端口不匹配。

{% hint style="info" %}
**您可以在[设置指南](../getting-started.md)部分找到代理设置示例**
{% endhint %}

## 路由规则设置

在开始之前，还必须配置路由。转至代理规则并指定代理设置。在我们的示例中，我们将代理计算机上的所有应用程序；在规则中，请务必指定规则流量应流向的位置。

<figure><img src="../../.gitbook/assets/Image00002 (10).PNG" alt=""><figcaption></figcaption></figure>

在代理规则中，指定之前创建的代理，以便流量可以通过它。

<figure><img src="../../.gitbook/assets/Image00001 (8).PNG" alt=""><figcaption></figcaption></figure>

**完毕！您现在可以使用该应用程序。**
