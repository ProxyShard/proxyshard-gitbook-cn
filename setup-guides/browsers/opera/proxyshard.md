# ProxyShard Extension

我们官方的 <mark style="color:purple;">**ProxyShard – Smart Proxy Manager**</mark> 扩展程序可直接从 **Chrome Web Store** 安装到 Opera。

## 安装

打开扩展程序页面并点击安装按钮。如果 Opera 要求确认从 Chrome Web Store 安装，请允许该操作。
