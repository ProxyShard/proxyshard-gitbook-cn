# ShardExtension

我们的官方浏览器扩展 <mark style="color:purple;">**ShardExtension**</mark> 可直接从 **Chrome Web Store** 安装到 Opera。

## 安装

打开扩展程序页面并点击安装按钮。如果 Opera 要求确认从 Chrome Web Store 安装，请允许该操作。
