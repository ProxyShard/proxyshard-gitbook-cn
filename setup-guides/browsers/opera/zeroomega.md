# ZeroOmega

## **安装和设置** ZeroOmega

{% hint style="warning" %}
此解决方案不支持 UDP 隧道！为此，我们强烈建议考虑 [<mark style="color:green;">Vision</mark>](../../antidetect-browsers/vision-browser.md)
{% endhint %}

由于 Opera 支持 Chrome 扩展，因此我们建议使用 **ZeroOmega**。

对于 Opera，可以使用 [**ZeroOmega**](https://chromewebstore.google.com/detail/Proxy%20SwitchyOmega%203%20\(ZeroOmega\)/pfnededegaaopdmhkdmcofjmoldfiped) 扩展。安装它。

{% embed url="https://chromewebstore.google.com/detail/Proxy%20SwitchyOmega%203%20(ZeroOmega)/pfnededegaaopdmhkdmcofjmoldfiped" %}

<figure><img src="../../../.gitbook/assets/Image00002 (3).PNG" alt=""><figcaption></figcaption></figure>

安装扩展后，它将出现在右上角。单击它并固定扩展以方便使用。

<figure><img src="../../../.gitbook/assets/Image00004 (3).PNG" alt=""><figcaption></figcaption></figure>

\
打开扩展设置

<figure><img src="../../../.gitbook/assets/Image00003 (3).PNG" alt=""><figcaption></figcaption></figure>

在 ZeroOmega 设置界面中，创建一个新的配置文件并为其指定任意名称。

<div align="center"><figure><img src="../../../.gitbook/assets/image (134).png" alt=""><figcaption></figcaption></figure></div>

在此指定任何配置文件名称。

<figure><img src="../../../.gitbook/assets/image (135).png" alt=""><figcaption></figcaption></figure>

接下来，将打开服务器设置界面。从订单中的“代理列表”中获取代理并手动输入服务器 IP（或 DNS）、端口、登录名和密码。\
使用锁形图标 🔒 按钮设置登录名和密码。

<figure><img src="../../../.gitbook/assets/image (136).png" alt=""><figcaption></figcaption></figure>

在此输入代理登录名和密码。

<figure><img src="../../../.gitbook/assets/image (137).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
**您可以在[设置指南](../../getting-started.md)部分找到代理设置示例**
{% endhint %}

然后应用设置

<figure><img src="../../../.gitbook/assets/image (138).png" alt=""><figcaption></figcaption></figure>

在扩展弹出窗口中，选择您之前配置的代理。

<figure><img src="../../../.gitbook/assets/Image00001 (3).PNG" alt=""><figcaption></figcaption></figure>

**完毕！您已完成通过扩展设置代理。**\
**您现在可以开始使用代理。**
