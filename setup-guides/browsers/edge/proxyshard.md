# ProxyShard Extension

我们官方的 <mark style="color:purple;">**ProxyShard – Smart Proxy Manager**</mark> 扩展程序在 Microsoft Edge 中可无限制使用，因为 Edge 基于 Chromium 内核构建，支持来自 **Chrome Web Store** 的扩展程序。

{% hint style="info" %}
首次从 Chrome Web Store 安装扩展时，Edge 可能会提示「**允许来自其他商店的扩展程序**」，请确认此权限。
{% endhint %}
