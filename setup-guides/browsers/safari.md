# Safari

不幸的是，<mark style="color:purple;">Safari</mark> 浏览器没有可用的扩展。它不支持具有此功能的附加组件，但您可以考虑替代选项：\
1\) [MacOS 安装](../macos/)\
2\) [反检测浏览器](../antidetect-browsers/)\
3\) 安装 [Chrome](chrome/)、[Mozilla Firefox](mozilla-firefox/) 或其他支持扩展程序的浏览器（Opera、Brave、Vivaldi ...）
