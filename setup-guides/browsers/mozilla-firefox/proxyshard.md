# ProxyShard Extension

我们的官方 <mark style="color:purple;">**ProxyShard – Smart Proxy Manager**</mark> 扩展程序可让您直接在 Mozilla Firefox 中管理代理。请从 **Firefox Add-ons** 安装。

{% embed url="https://addons.mozilla.org/en-US/firefox/addon/proxyshard-smart-proxy-manager/" %}

{% hint style="success" %}
Mozilla Firefox 版本支持通过扩展程序使用 <mark style="color:purple;">**SOCKS5**</mark>。
{% endhint %}
