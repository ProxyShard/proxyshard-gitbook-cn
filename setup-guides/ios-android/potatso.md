# Potatso

## 安装 Potatso

从 App Store 安装 Potatso。

{% embed url="https://apps.apple.com/app/potatso/id1239860606" %}

## 配置 Potatso

打开应用，然后点击 `Add Servers`。

<figure>
  <picture>
    <source srcset="../../.gitbook/assets/potatso-ios-add-servers_black.png" media="(prefers-color-scheme: dark)">
    <img src="../../.gitbook/assets/potatso-ios-add-servers_white.png" alt="在 Potatso 中添加服务器">
  </picture>
</figure>

选择 `Manual Input`。

<figure>
  <picture>
    <source srcset="../../.gitbook/assets/potatso-ios-manual-input_black.png" media="(prefers-color-scheme: dark)">
    <img src="../../.gitbook/assets/potatso-ios-manual-input_white.png" alt="在 Potatso 中手动输入配置">
  </picture>
</figure>

## 配置代理

选择连接类型，并使用订单 `Proxy List` 中的数据填写表单：

1. 输入服务器地址和端口。
2. 输入用户名和密码。
3. 保存配置。

<figure>
  <picture>
    <source srcset="../../.gitbook/assets/potatso-ios-add-server-form_black.png" media="(prefers-color-scheme: dark)">
    <img src="../../.gitbook/assets/potatso-ios-add-server-form_white.png" alt="在 Potatso 中配置代理">
  </picture>
</figure>

{% hint style="info" %}
数据格式和订单示例请参阅[开始使用](../getting-started.md)。
{% endhint %}

选择刚才创建的配置，然后启用连接。

<figure>
  <picture>
    <source srcset="../../.gitbook/assets/potatso-ios-connect_black.png" media="(prefers-color-scheme: dark)">
    <img src="../../.gitbook/assets/potatso-ios-connect_white.png" alt="在 Potatso 中连接代理">
  </picture>
</figure>

代理现已连接，可以在 Potatso 中使用。
