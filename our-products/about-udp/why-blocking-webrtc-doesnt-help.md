# 为什么阻止 WebRTC 并不能保护您免受检测

市场上几乎所有反检测浏览器都会简单地阻止 <mark style="color:purple;">WebRTC</mark> 以防止泄露。但这也是一个危险信号。对于大多数普通用户来说，<mark style="color:purple;">WebRTC</mark> 可以工作，如果它被禁用，那看起来也很可疑。

{% hint style="danger" %}
**唯一正确的做法是不阻止**<mark style="color:purple;">**WebRTC**</mark>**，而是通过UDP代理正确代理它。为此，浏览器或软件以及代理本身都必须支持它。**
{% endhint %}
