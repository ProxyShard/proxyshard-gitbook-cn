# 如何检查 WebRTC 泄漏

有多种服务可以帮助检查 WebRTC 泄漏。我们建议从我们自己的工具开始。

## 1. ProxyShard IP Checker

<mark style="color:purple;">**推荐**</mark>使用我们的工具。它会显示 IP 地址和地理位置，并立即检测 <mark style="color:purple;">WebRTC</mark> 泄漏。

{% embed url="https://proxyshard.com/ip-checker" %}

{% hint style="danger" %}
如果页面显示 **“**<mark style="color:purple;">**WebRTC is leaked**</mark>**”**，并列出了其他 IP 地址，则其他网站可能看到您的真实地址。
{% endhint %}

{% hint style="info" %}
