# 余额充值

余额可用于购买产品、续订订单以及支付额外流量。最低充值金额为 **$5**。

充值步骤：

1. 打开 [`Wallet`](https://dashboard.proxyshard.com/en/wallet)。
2. 在 `Top up balance amount` 中输入充值金额。
3. 在 `Payment method` 中选择付款方式。
4. 点击 `Top up your balance` 并完成付款。

`Payment method` 列表提供以下选项：

* `Credit Card / Google Pay` - 使用银行卡或 Google Pay 付款，由 Stripe 处理。
* `Nowpayments (Crypto)` - 使用加密货币付款。
* `USDT TRC20` - 通过 TRC20 (TRON) 网络支付 USDT 的独立选项。

{% hint style="warning" %}
通过 TRC20 网络支付 USDT 时，请选择 `USDT TRC20`。支付服务商会按比例收取手续费，因此该付款方式的最低金额为 **$21**。
{% endhint %}

`History` 区域会显示每次充值的金额、状态和日期。点击 `Open` 可查看账单，并按需下载 PDF 文件。
