# 住宅代理购买示例

## 购买代理

由于 <mark style="color:purple;">Residential</mark> 代理以 GB 为单位计费，因此您需要指定要购买的流量以及促销代码（如果有）

{% hint style="info" %}
未使用的流量不会在月底失效；它会保留在订单中，直到全部用完。
{% endhint %}
