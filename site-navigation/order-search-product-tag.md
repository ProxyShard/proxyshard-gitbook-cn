# 订单搜索（产品标签）

每个订单允许您设置一个<mark style="color:purple;">Product-Tag</mark>

<figure><img src="../.gitbook/assets/image (255).png" alt="" width="506"><figcaption></figcaption></figure>

订单左侧指定任意名称；在此示例中，使用“<mark style="color:$info;">test\_tag1</mark>”

然后在“<mark style="color:purple;">活跃产品</mark>”或“<mark style="color:purple;">我的订单</mark>”中，您可以看到标签如何应用到订单。

<figure><img src="../.gitbook/assets/image (256).png" alt="" width="563"><figcaption></figcaption></figure>

使用“搜索”字段 ![](<../.gitbook/assets/image (258).png>)，您可以按标签查找订单

<figure><img src="../.gitbook/assets/image (259).png" alt="" width="563"><figcaption></figcaption></figure>

订单可在商品页面和[订单](https://dashboard.proxyshard.com/products)列表中搜索
