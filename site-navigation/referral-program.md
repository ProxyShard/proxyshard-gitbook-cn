# 推荐计划

`Affiliate` 页面包含您的专属推荐链接。点击 `Copy link` 后，即可将链接发送给要邀请的用户。

您邀请的用户产生购买时，您可获得 10% 的一级佣金。如果该用户继续邀请新客户，您还可从新客户的购买中获得 10% 的二级佣金。

如需自定义推荐链接末尾的内容，请点击链接旁边的铅笔图标并保存新值。此页面还会显示收益、未支付佣金以及各级推荐人数。
